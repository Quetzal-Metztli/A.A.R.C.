Qué entiendes por soberanía digital?
	la soberanía digital es dejar de depender de esas empresas de software capitalistas y usar alternativas de software libre 
> Que se necesita para que un software sea libre?
	Según la fundación del software libre que lo defiende se necesitan de 4 libertades para un programas ser software libre:
	- **Libertad 0:** Libertad de **ejecutar** el programa como quieras y para cualquier propósito.
	- **Libertad 1:** Libertad de **estudiar** cómo funciona el programa y cambiarlo (para lo cual el acceso al código fuente es obligatorio).
	- **Libertad 2:** Libertad de **redistribuir** copias para ayudar a otros.
	- **Libertad 3:** Libertad de **distribuir copias de tus versiones modificadas** a terceros.
